# English Panda

Браузерная игра для изучения английского: долина с бамбуковой рощей, водопадом, деревней и чайным домом, уровни с мини-играми, словарь, Книга духов и Лавка.

## Запуск
```bash
python3 serve.py
```
Открыть http://localhost:5188. Сборка не нужна, прогресс хранится в `localStorage` браузера.

## Что внутри
- Глава 1 «Весна · A1»: 9 уровней + экзамен «Врата весны» (сертификат A1).
- Глава 2 «Лето · A2»: рисовые террасы, озеро лотосов, летний рынок, горный монастырь; 9 уровней + экзамен «Врата лета» (сертификат A2). Слова, предложения и диалоги: `src/learn/words2.js`.
- 17 мини-игр: Знакомство, Пары, Печать, Вставь пропуск, Скоропись, Каллиграфия, Судоку слов, Сборщик фраз, Дуэль с духом, Рыбалка, Корзины, Поиск слов, Кроссворд, Разговор, Верно или нет, Фонарь, Цепочка памяти. Без озвучки: только чтение и печать.
- Повторение по Лейтнеру (`src/learn/srs.js`), подсказки-загадки за монеты (`src/learn/hints.js`).
- Пара языков: «я говорю на» (русский / чешский) и «хочу учить» (английский / русский / чешский). У каждого изучаемого языка своё сохранение. Загадки и примеры для RU/CZ: `src/learn/words-i18n.js`, раскладки клавиатуры: `src/learn/lang.js`.
- Смена дня по прокрутке или по часам, сезоны в настройках.

## Как добавить уровни
Слова: `src/learn/words.js`. Уровни: `LEVELS` в `src/learn/curriculum.js`. Духи: `src/learn/mobs.js`.
