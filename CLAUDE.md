# English Panda
Игра для изучения языков. Без сборки (ES-модули), `python3 serve.py` → порт 5188. `git push` в main = деплой на Vercel.
Чат по-русски, коротко, вопросы через окно выбора.
- Графика: сначала прочитать `design/README.md` и посмотреть `design/refs/`.
- Обучение (темы, слова, игры): сначала прочитать `learning/README.md`.

## Тесты — перед каждой выкладкой
- `node tests/data.mjs` — данные всех языковых пар: задания, ответы среди вариантов, уроки, слова, духи, порядок камней.
- Браузер: `http://localhost:5188/?smoke=all` — запускает каждый этап каждого уровня во всех парах, ловит ошибки и пустые экраны. Итог в заголовке вкладки (SMOKE OK / SMOKE FAIL) и в `window.__SMOKE`. Для одной пары: `?smoke=en-ru`.
- Если игра на сайте не загрузилась (сайт обновился во время игры), страница перезагружается сама; если игра падает — кнопка «Пропустить этап».
