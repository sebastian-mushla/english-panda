# Дизайн English Panda — бриф для художника и Claude

Читать перед любой работой с графикой. Референсы лежат в `refs/` (по папкам).

## Стиль (что хочу)
- Рисованная, «живописная» картинка, как акварель или гуашь: мягкий свет, глубина, детали.
- Никакого «как ребёнок нарисовал»: плоские фигуры, один цвет на объект и пустые интерьеры запрещены.
- Тема: Китай, панда, бамбук, туман, фонари, мох, камень, вода.
- Свет: тёплый золотой (фонари, проёмы) против холодного (пещеры, ночь, вода).

## Входы в места (на карте)
- Вход нарисован физически на объекте: дверь дома, пасть пещеры в скале, тоннель в горе, ступени вниз к фонтану, ворота храма.
- Обязательно: мох, лианы, папоротник, трещины в камне, свет из проёма.
- Референс: `refs/entrances/` (пещера с мхом).

## Интерьеры (внутри места)
- Картина 16:9 на весь экран, на телефоне листается вбок.
- Тропа с камнями-фазами идёт по сцене.
- Пещера: светящаяся вода, кристаллы, золотой проём вдали. Референс: `refs/interiors/`.
- Дом мастера: сёдзи, полки со свитками, фонари, татами.

## Технические правила
- SVG без filter и blend-mode (тормозят телефоны). Слои мира — размером с экран, двигаются через viewBox.
- Кисти: `src/world/art.js` (rock, moss, vine, fern, crystal, glow). Входы: `src/world/entrances.js`. Интерьеры: `src/world/interiors.js`.
- Свои или лицензионные картинки (PNG/WebP ≤ 300 КБ) класть в `design/refs/` с пометкой «можно в игру». Картинки из Google без лицензии в игру не идут.
