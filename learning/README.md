# Обучение — бриф по методике

Читать перед добавлением тем, слов и игр.

## Принципы
- Сначала учим, потом спрашиваем: в начале темы стоит урок-правило. Во время уровня правило не открывается.
- Подсказки помогают написать слово: эмодзи и значение → маска «m _ _ _ ý» и число букв → половина букв и пример. Загадки на изучаемом языке не используются.
- Освоение: финальная проверка из 10 заданий без подсказок, порог 80 %.
- Ошибки уходят в повторение (Leitner, `src/learn/srs.js`).

## Структура
- Камень на карте = тема. Большая тема = место (пещера, дом, гора…) с фазами.
- Фаза: правило → узнавание (maze/sokoban) → форма (verbform) → найди ошибку → проверка.
- Языки: родные ru, uk, cz; изучаемые en, cz (полная программа до B2), ru и hu (только слова).

## Программа (статус)
- EN A1: готово. Дальше A2: Present Continuous, Past Simple, was/were, some/any/much/many, сравнения, will/going to, must/have to/should, наречия, object pronouns.
- Потом EN B1, B2, затем CZ A1–B2. Полный список: план `~/.claude/plans/reflective-chasing-umbrella.md`.
- Слова: цель A1 ~500, A2 ~1000, B1 ~2000, B2 ~3000.
